Detail Tahapan Teknis

1. Registrasi Akun & Data Awal

Calon siswa memulai dengan membuat akun menggunakan Nama Lengkap, NIK (16 digit, unik), Email, dan Password. Sistem akan membuat user baru dan mengarahkan ke dashboard.

2. Pengisian Formulir Pendaftaran (Tahap 1)

Siswa mengisi formulir pendaftaran melalui wizard 4 langkah:

  • Langkah 1: Data Pribadi (Biodata, Alamat), dan Data Orang Tua.
  • Langkah 2: Data Sekolah Asal, Jalur Pendaftaran, Penjadwalan Tes (jika berlaku), dan Input Nilai Rapor (Kelas 4-6).
  • Langkah 3: Upload Dokumen Wajib (Surat Keterangan Nilai, Pas Foto) & Dokumen Khusus (Sertifikat).
  • Langkah 4: Review ringkasan data dan submit.

3. Verifikasi & Seleksi

Admin memverifikasi data. Status flow:

  • Submitted -> Verified (Data valid).
  • Submitted -> Revision (Ada data kurang, siswa harus edit ulang).
  • Submitted -> Rejected (Tidak memenuhi syarat).

Status Data Siswa

Status Deskripsi Aksi Siswa
Draft Formulir belum dikirim. Bisa edit dan submit.
Submitted Formulir dikirim, menunggu verifikasi. Tidak bisa edit (Read-only). Bisa ajukan revisi.
Revision Admin meminta perbaikan data. Bisa edit dan submit ulang.
Verified Data administrasi valid. Cetak Kartu Ujian. Menunggu pengumuman.
Accepted Lulus seleksi. Akses menu Daftar Ulang.
Rejected Tidak lulus seleksi. Selesai.
